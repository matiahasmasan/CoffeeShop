# Coffee Shop App

A web application for managing coffee shop loyalty cards, store information, and barista profiles.

## Tech Stack

- **Frontend**: React, Vite
- **Backend**: Node.js, Express
- **Testing**: Jest

## Project Structure

```
backend/       - Node.js/Express server and APIs
frontend/      - React application with Vite
```

## Setup

### Prerequisites

- Node.js 14+
- npm or yarn

### Installation

Install dependencies for both frontend and backend:

```bash
cd backend
npm install

cd ../frontend
npm install
```

## Running the App

**Backend:**

```bash
cd backend
npm start
```

**Frontend:**

```bash
cd frontend
npm run dev
```

## Development

This app is currently in development. Check individual README files in the `backend/` and `frontend/` directories for specific setup instructions.

## Testing

Backend tests are located in `backend/src/tests/`.

```bash
cd backend
npm test
```
